# Psykeidos 开发日志

Psykeidos 是独立项目，承继 Emotion Mask 的情绪切换与 2.5D 角色探索。Emotion Mask 的原项目页继续保留，两页相互说明继承关系。当前日志记录 Blender 世界地图的真实迭代，不代表已经完成游戏整合。

## 内容入口

- 项目介绍：`apps/site/src/content/projects/psykeidos/index.md` 和 `index.en.md`。
- 每轮报告：`apps/site/src/data/psykeidos-devlogs.ts`，使用稳定且唯一的版本 ID。
- 日志列表：`/projects/psykeidos/devlog/`，英文入口在 `/en/` 下。
- 单轮记录：`/projects/psykeidos/devlog/<version>/`。
- 公开图片：`apps/site/public/content-assets/projects/psykeidos/`。

## 每轮发布

1. 先保存独立模型版本，完成本轮修改与必要技术检查，再从同一保存模型输出实际多视图。保留相机与版本记录；概念参考必须单独标明。
2. 为本轮新增一条双语记录：具体修改、真实检查、未解决问题、下一步建议及图片说明。技术检查和美术验收分别填写；只有明确验收后才更新美术状态。
3. 用真实渲染制作网页图片，保留画幅与比例。不要公开私人邮件、邮箱地址、绝对磁盘路径、内部交接、凭据或未经要求发布的模型源文件。
4. 执行媒体优化、内容检查、测试、类型检查、构建及链接检查。检查中文和英文页面，以及桌面和手机布局。
5. 按仓库现有主分支发布流程推送，等待部署成功，并实际打开公开地址和图片确认新版本。
6. 部署确认后，在既有验收邮件线程发送一次简短完成通知和该轮固定网址，不附成果包。先记录版本与部署标识防止重复发送；发送结果不明时检查已发送记录，不直接重发。
7. 有效反馈须对应当前成果版本。先登记新增反馈，再保存现状并按既有授权修改；冲突或越界要求由项目负责人确认。无新反馈时不重复通知。
